## Recursos adicionales (recursos/)

Esta sección recopila los recursos más valiosos para aprender y practicar Inteligencia Artificial en todos los niveles. Desde libros fundamentales hasta comunidades activas, estos recursos amplían el conocimiento y proporcionan apoyo continuo en el camino de convertirse en especialista en IA.

### Libros recomendados

#### Libros fundamentales para comenzar

- **"Inteligencia Artificial: Una guía moderna" (Artificial Intelligence: A Modern Approach) - Stuart Russell y Peter Norvig**: El libro de referencia más respetado en IA. Cubre ampliamente desde búsqueda y lógica hasta aprendizaje automático. Excelente para principiantes que quieren fundamentos sólidos. Disponible en múltiples idiomas.

- **"Deep Learning" - Ian Goodfellow, Yoshua Bengio y Aaron Courville**: Libro completo sobre redes neuronales profundas. Escrito por pioneros del deep learning, cubre teoría y práctica. Requiere conocimientos matemáticos sólidos pero muy comprehensive.

- **"Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow" - Aurélien Géron**: Enfoque práctico y accesible. Código en Jupyter notebooks, perfecta para aprender haciendo. Una de las mejores introducciones prácticas disponibles.

#### Libros especializados

**Aprendizaje Automático**:
- **"Machine Learning Yearbook" - Andrew Ng**: Compilación de papers y tendencias, excelente para mantenerse actualizado.
- **"The Hundred-Page Machine Learning Book" - Andriy Burkov**: Resumen conciso de conceptos clave ML, ideal para referencia rápida.
- **"Pattern Recognition and Machine Learning" - Christopher Bishop**: Cobertura exhaustiva probabilística de ML, riguroso matemáticamente.

**Aprendizaje Profundo**:
- **"Neural Networks and Deep Learning" - Michael Nielsen**: Libro online gratuito, excelente para entender principios fundamentales con visualizaciones interactivas.
- **"Grokking Deep Learning" - Andrew Trask**: Enfoque visual e intuitivo sin dependencia excesiva de fórmulas matemáticas.

**Visión por Computadora**:
- **"Computer Vision: Algorithms and Applications" - Richard Szeliski**: Referencia comprehensiva de algoritmos de visión clásicos y modernos.
- **"Digital Image Processing" - Rafael González y Richard Woods**: Estándar en procesamiento de imágenes digital.

**Procesamiento de Lenguaje Natural**:
- **"Speech and Language Processing" - Daniel Jurafsky y James Martin**: Cobertura completa de NLP desde fundamentos a métodos modernos. Versión 3 con deep learning disponible online.
- **"Natural Language Processing with Transformers" - Lewis Tunstall, Leandro von Werra y Thomas Wolf**: Guía práctica para usar Hugging Face Transformers.

**Aprendizaje por Refuerzo**:
- **"Reinforcement Learning: An Introduction" - Richard Sutton y Andrew Barto**: Libro definitivo en RL, matemáticamente riguroso pero accesible.
- **"Deep Reinforcement Learning Hands-On" - Maxim Lapan**: Enfoque práctico con código PyTorch.

#### Libros sobre temas transversales

- **"Thinking, Fast and Slow" - Daniel Kahneman**: Psicología de toma de decisiones, fundamental para entender sesgos en datos y modelos.
- **"Weapons of Math Destruction" - Cathy O'Neil**: Impacto social de algoritmos ML, importante para consideraciones éticas.
- **"The Alignment Problem" - Brian Christian**: Desafíos de alinear sistemas IA con valores humanos.

### Cursos recomendados

#### Cursos online de nivel principiante

- **"Machine Learning" - Andrew Ng (Coursera)**: Curso clásico con explicaciones claras. Cubre fundamentos ML con Octave. Gratuito para auditar, certificado de pago.

- **"Introduction to Data Science" - UC San Diego (Coursera)**: Introducción accesible a conceptos y herramientas de ciencia de datos.

- **"Python for Data Science" - IBM (Coursera)**: Aprende Python específicamente para ciencia de datos con librerías clave.

- **"Foundations of Data Science" - UC Berkeley (edX)**: Curso universitario en probabilidad, inferencia estadística, computación.

#### Cursos de nivel intermedio

- **"Deep Learning Specialization" - Andrew Ng (Coursera)**: Serie de 5 cursos cubriendo CNN, RNN, estructuración de proyectos ML.

- **"Practical Deep Learning for Coders" - Fast.ai**: Top-down approach, aprende haciendo primero con código simple. Excelente comunidad.

- **"Convolutional Neural Networks" - Stanford CS231n**: Curso universitario de referencia en visión por computadora. Videos y materiales disponibles online gratis.

- **"Natural Language Processing with Deep Learning" - Stanford CS224n**: Curso universitario en NLP moderno con transformers. Materiales completos disponibles.

- **"Full Stack LLM Bootcamp" - AI.Engineer**: Entrenamiento práctico en construcción de aplicaciones con modelos de lenguaje grandes.

#### Cursos de nivel experto

- **"Advanced Deep Learning & Reinforcement Learning" - DeepMind x UCL**: Colaboración entre DeepMind y University College London, cubre tópicos avanzados.

- **"Large Language Models" - Stanford CS224n (módulo avanzado)**: Foco específico en transformers, training a escala, fine-tuning.

- **"Machine Learning Systems Design" - Varios (YouTube, blogs)**: MLOps, production ML, infrastructure considerations.

- **"Mechanistic Interpretability" - Anthropic, Redwood Research**: Cómo entender internamente cómo funcionan modelos neuronales.

#### Alternativas y recursos de aprendizaje

- **YouTube**: Canales como StatQuest (estadística), 3Blue1Brown (matemática visual), Jeremy Howard (práctico).

- **Papers con código (Papers with Code)**: Accede papers académicos con implementaciones de código, observa resultados replicados.

- **Distill.pub**: Artículos visuales e interactivos explicando conceptos complejos de ML.

### Datasets recomendados

#### Repositorios principales de datasets

- **Kaggle Datasets**: Plataforma más grande con miles de datasets públicos de todas las áreas. También competiciones para practicar.

- **UCI Machine Learning Repository**: Datasets clásicos bien documentados, referencia histórica en ML.

- **Google Dataset Search**: Motor de búsqueda para datasets públicos en internet.

- **Hugging Face Datasets**: Librería de 1000+ datasets para NLP y visión, integración directa en código.

- **GitHub**: Muchos investigadores publican datasets personalizados en repositorios.

#### Datasets por área y nivel

**Nivel Principiante**:
- **Iris**: Clasificación de flores, 150 muestras, dataset clásico para comenzar.
- **MNIST**: Dígitos manuscritos, 70K imágenes 28x28. Estándar para hello world en deep learning.
- **Titanic**: Predicción de supervivencia, clasificación binaria clásica.
- **Boston Housing**: Predicción de precios de viviendas, regresión simple.
- **CIFAR-10**: Clasificación de objetos, 60K imágenes 32x32 (10 clases).

**Nivel Intermedio**:
- **ImageNet**: Millones de imágenes etiquetadas, estándar para visión por computadora. ILSVRC challenge.
- **COCO**: 330K imágenes con anotaciones ricas (detección, segmentación, caption). Benchmark principal.
- **CIFAR-100**: Extensión de CIFAR-10 con 100 clases, mayor complejidad.
- **STL-10**: Subconjunto de ImageNet con etiquetas limitadas, para semi-supervised learning.
- **WikiText**: Corpus de texto de Wikipedia para NLP y language modeling.
- **IMDb Reviews**: 50K críticas de películas para análisis de sentimientos.
- **SQuAD**: Stanford Question Answering Dataset, preguntas sobre párrafos para machine reading comprehension.

**Nivel Experto**:
- **The Pile**: Conjunto diverso y masivo de 825GB texto web para preentrenamiento de LLMs.
- **SlimPajama**: Versión compilada y deduplicated de web crawl para entrenamiento eficiente.
- **OpenWebText**: Texto de web crawl de alta calidad para language models.
- **Laion-5B**: 5.85 billones pares imagen-texto de internet, base de muchos modelos multimodales.
- **CommonCrawl**: Crawl público de web con petabytes de contenido.
- **Academic datasets**: ArXiv, PubMed, biomedical literature para domain-specific fine-tuning.

#### Plataformas de datos especializadas

- **OpenML**: Plataforma para compartir datasets y experimentos, permite comparar algoritmos.

- **Registry of Open Data on AWS (RODA)**: Datasets públicos alojados en AWS S3, acceso gratuito.

- **Google Cloud Public Datasets**: Datasets públicos en BigQuery para análisis grande escala.

- **Azure Open Datasets**: Datasets curados por Microsoft en Azure.

### Herramientas y frameworks

#### Frameworks de Deep Learning

| Framework | Lenguaje principal | Ventajas | Casos de uso |
|-----------|-------------------|----------|-------------|
| **PyTorch** | Python | API intuitiva, investigación flexible, adoption academia | Investigación, NLP avanzado, visión |
| **TensorFlow/Keras** | Python | Ecositema maduro, production-ready, documentación extensa | Producción, aplicaciones enterprise |
| **JAX** | Python | Transformaciones funcionales, diferenciación automática flexible | Investigación matemática, computación científica |
| **MXNet** | Multi-lenguaje | Eficiente en memoria, soporte distributed | Producción a escala |
| **Hugging Face Transformers** | Python | Modelos preentrenados fáciles de usar, comunidad activa | NLP, modelos preentrenados |

#### Herramientas de procesamiento de datos

- **Pandas**: Manipulación y análisis de datos tabulares en Python. Estándar de facto.
- **Polars**: Alternativa moderna a Pandas, más rápido para datasets grandes.
- **NumPy**: Computación numérica, operaciones array eficientes.
- **Scikit-learn**: Algoritmos clásicos de ML (regresión, clasificación, clustering).
- **Dask**: Cómputo paralelo distribuido para datos que no caben en memoria.
- **Apache Spark**: Procesamiento big data distribuido, integración con ML libs.

#### Herramientas de visualización

- **Matplotlib**: Plotting fundamental, control fino pero sintaxis verbosa.
- **Seaborn**: Visualización estadística construida sobre Matplotlib, hermosas por defecto.
- **Plotly**: Visualizaciones interactivas modernas, excelente para dashboards.
- **Altair**: Visualización declarativa basada en Vega-Lite, intuitiva.
- **Tensorboard**: Herramienta de TensorFlow para visualizar entrenamientos, gráficos, embeddings.

#### Herramientas de experimentación y tracking

- **Weights & Biases (W&B)**: Tracking completo de experimentos, hyperparameter logging, visualización.
- **MLflow**: Plataforma open-source para ciclo de vida ML, versionado de modelos.
- **Weights & Biases Reports**: Documentación automática de experimentos en notebooks.
- **Neptune.ai**: Tracking de experimentos colaborativo, integración con frameworks.
- **Comet ML**: Plataforma enterprise para tracking, optimization, reproducibilidad.

#### Herramientas de optimización de modelos

- **NVIDIA TensorRT**: Optimización y despliegue de modelos en GPUs NVIDIA.
- **TensorFlow Lite**: Framework para modelos en dispositivos móviles y edge.
- **ONNX Runtime**: Ejecución de modelos en múltiples plataformas.
- **OpenVINO**: Herramienta Intel para optimización y despliegue en CPUs.
- **Ollama**: Ejecuta LLMs localmente en máquina personal con facilidad.

#### Herramientas de despliegue

- **Docker**: Containerización de aplicaciones, reproducibilidad, portabilidad.
- **Kubernetes**: Orquestación de contenedores para aplicaciones a escala.
- **FastAPI**: Framework web moderno para construir APIs ML rápidamente.
- **Flask**: Framework web simple para servir modelos.
- **Streamlit**: Crea aplicaciones interactivas para ML sin frontend expertise.
- **Gradio**: Crea interfaces web para modelos con pocas líneas de código.
- **Ray Serve**: Despliegue escalable de modelos ML con Ray.
- **BentoML**: Framework para packaging y despliegue de modelos ML.

#### Herramientas cloud

- **Google Colab**: Notebooks Jupyter con GPU gratuito, ideal para learning y experimentación.
- **Kaggle Notebooks**: Ambiente similar a Colab, integración con datasets Kaggle.
- **AWS SageMaker**: Servicio completo ML en Amazon Web Services.
- **Google Cloud Vertex AI**: Plataforma ML completa de Google Cloud.
- **Microsoft Azure ML**: Solución ML end-to-end de Microsoft.
